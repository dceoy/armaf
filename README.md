armaf
=====

ARIMA-based Forex Trader using Oanda API

[![Test](https://github.com/dceoy/armaf/actions/workflows/test.yml/badge.svg)](https://github.com/dceoy/armaf/actions/workflows/test.yml)
[![CI to Docker Hub](https://github.com/dceoy/armaf/actions/workflows/docker-compose-build-and-push.yml/badge.svg)](https://github.com/dceoy/armaf/actions/workflows/docker-compose-build-and-push.yml)

Installation
------------

```sh
$ pip install -U https://github.com/dceoy/armaf/archive/main.tar.gz
```

Usage
-----

Run `armaf --help`.
